How it works

Set it up in 2 minutes,
get value on the first PR

1

Define your goal

Commit a .socratic/goal.json with your current goal, milestone, and success metric. Add constraints that your future self must not violate.

2

Add the workflow

Copy one 12-line YAML file to .github/workflows/. Add your OpenRouter API key as a secret. Done.

3

Every PR gets reviewed

Socratic posts a structured comment on every PR. Findings are grounded in your actual goal — not generic best practices.

.github/workflows/socratic-review.yml
name: Socratic Review
on:
  pull_request:
    types: [opened, synchronize, reopened]

jobs:
  socratic-review:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write
      contents: read
    steps:
      - uses: actions/checkout@v4
      - uses: shivam952/Socatic-AI@main
        with:
          api-key: ${{ secrets.SOCRATIC_API_KEY }}
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
